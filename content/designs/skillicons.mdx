# Background

The existing skill-icon sets I could find on GitHub don't include the tools I reach for daily. So I made my own with a single house style: a flat single-color glyph centered on a brand-color squircle, 256×256. Sources live in [zrosenbauer/art](https://github.com/zrosenbauer/art).
